# Step 3（前半）: 情報更新の報告導線と緊急相談先 — 要求

> 関連: [`docs/development-roadmap.md`](../../docs/development-roadmap.md) Step 3
> 本作業は Step 3 のうち「報告導線」「緊急相談先」を対象とする。**アクセス解析は次の作業**に回す。

## 1. 目的

- 掲載情報の誤り・古さに気づいた利用者が、その場で運営者へ知らせられるようにする。
- いま助けが必要な子ども・家族が、**実在する相談先**にすぐたどり着けるようにする（現状は「準備中」相当の案内のみ）。

## 2. 要求内容

### A. 情報が古い場合の報告導線

- 施設詳細ページの「この情報が古い場合は知らせる」を、無効化されたボタンから**実際に開くリンク**にする。
- 遷移先: 運営者が用意した Google フォーム。
- 外部サイトへ遷移することが利用者に分かる表示にし、新しいタブで開く。

### B. 緊急相談先（「今すぐ助けが必要な場合」）

子ども向けの相談窓口2件を掲載する。

| 窓口 | 電話番号 | 説明文（指定） |
| --- | --- | --- |
| 24時間こどもSOSダイヤル | 0120-0-78310 | いじめや学校生活の悩みなどを24時間いつでも無料で相談できる |
| チャイルドライン | 0120-99-7777 | チャイルドラインは子どものための相談先です。ちょっとしたことでも、おしゃべりしたいだけでも大丈夫。どんなことでも話してね。 |

- 受付時間も併記する（24時間こどもSOSダイヤル: 24時間365日 ／ チャイルドライン: 18歳まで・毎日16時〜21時）。
- 電話番号はタップで発信できるようにする。
- **いのちに関わる危険（110番・119番）の案内は残す**。相談窓口とは性質が異なるため、区別して示す。

### C. 電話番号の発信リンク化（UI レビュー項目1）

- 施設詳細ページの電話番号もタップで発信できるようにする。相談方法が電話中心のサービスであり、Step 3 で対応する前提だったもの。

## 3. ユーザーストーリー

- **US-1**: 子どもとして、つらいときに電話番号をタップするだけで相談先につながってほしい。
- **US-2**: 子どもとして、「緊急のことでなくても相談していい」と分かる言葉で案内されたい。
- **US-3**: 利用者として、掲載内容が古いと気づいたら、その場で運営者に知らせたい。
- **US-4**: 利用者として、外部サイトへ移動するときは、移動することが事前に分かってほしい。

## 4. 受け入れ条件

- **AC-1**: 施設詳細の「この情報が古い場合は知らせる」がリンクとして機能し、Google フォームが**新しいタブ**で開く。
- **AC-2**: 同リンクに `rel="noopener noreferrer"` が付き、外部遷移であることが利用者に分かる表示になっている。
- **AC-3**: 緊急セクションに 24時間こどもSOSダイヤル（0120-0-78310）とチャイルドライン（0120-99-7777）が、指定された説明文つきで表示される。
- **AC-4**: 上記2件の電話番号が `tel:` リンクになっており、受付時間が併記されている。
- **AC-5**: 110番・119番の案内が引き続き表示され、相談窓口と区別されている。
- **AC-6**: 施設詳細ページの電話番号が `tel:` リンクになっている。
- **AC-7**: 緊急セクションが全ページ（トップ・検索結果・施設詳細）で従来どおり表示される。
- **AC-8**: 開発者向けの文言（「準備中」など未実装を示す表現）が緊急セクションと報告導線から無くなる。
- **AC-9**: 緊急相談先の定義に単体テストがあり、電話番号・受付時間・説明文が欠けていないことを検証する。
- **AC-10**: lint / typecheck / test / build がすべて成功する。

## 5. 制約事項

- **プライバシー**: 報告フォームは外部（Google フォーム）で完結させ、サイト側で相談内容や個人情報を受け取らない。フォームへ利用者情報を引き渡すクエリパラメータも付けない。
- **推測で埋めない**: 掲載する電話番号・受付時間は指定された内容と公的情報に限る。
- **スコープ外**:
  - アクセス解析2種（詳細閲覧数・公式クリック数）— Step 3 の残作業として次回
  - 施設データ（`data/seed/*.json`）の変更

## 6. 確認が必要だった点（設計判断）

| 論点 | 判断 |
| --- | --- |
| 指定された Google フォーム URL に `?usp=publish-editor` が付いている | これは**編集者向けプレビュー用**のパラメータのため除去し、標準の回答用 URL（`.../viewform`）を使う |
| 緊急相談先をシード JSON から読むか | シードに**チャイルドラインが未収録**。緊急相談先は施設検索の対象外で、区マスタと同じ「サイト共通の参照データ」の性格が強いため、`shared/domain` の定数として持つ |
| 110番・119番を残すか | 残す。指定の2件は「相談窓口」、110/119 は「通報」であり緊急度が異なるため、区別して併記する |
