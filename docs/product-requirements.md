# プロダクト要求定義書 (Product Requirements)

> 起点となる要求メモ: [`docs/ideas/initial-requirements.md`](./ideas/initial-requirements.md)

## 1. プロダクトビジョンと目的

**よこはま支援さがし**は、横浜市にある子ども・家庭向けの支援情報を、探しやすく・比較しやすく・利用につながりやすい形で整理し、公共的なデジタル基盤として公開する OSS である。

- **ビジョン**: 子どもや家族が、必要な支援を見つけられずに孤立することを減らす。支援者が情報検索・確認作業に追われる時間を減らす。地域の支援資源を誰もが利用できる公共的なデジタル基盤として育てる。
- **MVP の目的**: 「横浜市内の不登校支援」に絞り、**問い合わせをしなくても公開情報を分かりやすく確認でき、3問の質問で自分に合いそうな支援先を2〜3件見つけられる**状態をつくる。

### 理念（技術の使い方）

技術で支援現場を支え、支援者が子どもと家族への支援に全力で取り組める環境をつくる。技術を子どもや家族の**監視・評価・分類には使わない**。検索・確認・転記・情報更新の負担を減らし、対話や支援に使える時間を増やすために使う。

## 2. ターゲットユーザーと課題・ニーズ

### 対象利用者

| 区分 | 対象 |
| --- | --- |
| 主対象 | 子ども本人 / 保護者・家族 / 学校関係者 |
| 対象範囲 | 子どもに関わるすべての人（支援者を含む） |

- **最初の利用場面**: 保護者が、自分の子どもの不登校について、学校以外に相談したいと思ったとき。

### 課題

- 「横浜市 不登校支援」等で検索しても、横浜市の分かりにくいポータルが中心に表示される。
- 支援先ごとの違い、および問い合わせ前に確認できる公開情報が直感的に把握しづらい。

### ニーズ（問い合わせ前に確認したい基本情報）

対象地域 / 相談内容 / 費用 / 予約の要否 / 相談方法 / 匿名相談の可否 / 保護者だけでも相談可能か / 運営主体 / 受付時間。

## 3. 主要な機能の定義

1. **3問の絞り込みウィザード** — キーワードボタンで回答し、支援先候補を段階的に絞り込む（MVP は3問固定）。
2. **検索結果一覧** — 条件に合致した支援先をカード形式で表示。件数を明示。選択区優先＋隣接区も表示。
3. **施設詳細ページ** — 問い合わせ前に必要な公開情報を、モバイルファーストで縦方向に読みやすく提示。
4. **公式サイトへの導線** — 登録済みの施設は新しいタブで公式サイトへ。
5. **情報が古い場合の報告導線** — 運営者が用意する Google フォームへ遷移。
6. **緊急時の相談先** — 全詳細ページ下部に共通セクションを固定表示。
7. **確認状況の表示** — 運営者確認済み / 公式情報確認済み / 未確認 の3段階。ランキングは行わない。
8. **最小限のアクセス解析** — 詳細ページ閲覧数、「公式サイトを見る」クリック数のみ。

## 4. ユーザーストーリー

- **US-01**: 保護者として、子どもの不登校について学校以外の相談先を、3問答えるだけで数件に絞って見たい。専門知識がなくても選べるようにしたい。
- **US-02**: 保護者として、問い合わせる前に「保護者だけでも相談できるか」「無料か」「予約が要るか」を確認したい。
- **US-03**: 利用者として、選んだ区の施設だけでなく、通いやすい隣接区の施設も、区名が分かる形で見たい。
- **US-04**: 子ども本人として、匿名で相談できるか・学校を通さず使えるかを知りたい。
- **US-05**: 学校関係者・支援者として、担当する子どものために地域資源を素早く確認・比較したい。
- **US-06**: 利用者として、掲載情報が古かったら簡単に報告したい。
- **US-07**: 危機的状況にある利用者として、緊急の相談先へ即座にたどり着きたい。
- **US-08**: コントリビューターとして、施設情報を Pull Request で追加・修正したい。

## 5. 受け入れ条件（主要）

- **AC-01**: トップから3問（誰のために / 困りごと / 地域）に答えると検索結果に到達できる。4問目は存在しない。
- **AC-02**: Q1・Q2 で「その他」を選んだ場合のみ自由記述欄が表示され、未入力では次へ進めない。
- **AC-03**: Q2・Q3 は単一選択。Q2 は「最も困っていること」を1つだけ選ぶ。
- **AC-04**: 検索結果は「検索結果 ○件」と件数を明示し、初期表示件数を固定しない。
- **AC-05**: 検索結果は選択区の施設を優先し、隣接区の施設も所在地の区名付きで表示される。並び順は「選択区（一致度順）→ **市域全体の窓口**（一致度順）→ 隣接区（一致度順）」。区に属さない市域全体の窓口は、どの区を選んでも結果に含め、「市全域」と区別して表示する。
- **AC-06**: 各結果カードに、順位・施設名・運営主体・概要・区名・相談方法・費用・対象/条件タグ・確認状況・詳細への導線が表示される。
- **AC-07**: 検索結果画面から条件を変更・再検索できる。
- **AC-08**: 詳細ページに要求メモ記載の全項目が表示される（[initial-requirements](./ideas/initial-requirements.md) の詳細ページ節）。
- **AC-09**: 未確認・未掲載の項目を空欄にしない。詳細ページでは該当項目を表に並べる代わりに、末尾の「公式サイトで確認が必要な項目」に**項目名を列挙**し、推測で補っていないことを明示する。一覧では概要が未登録の場合、出典で確認できている情報（対象年齢など）を代わりに表示する。
- **AC-10**: 公式サイト URL がある施設のみ「公式サイトを見る」ボタンを表示し、押下で新しいタブ・外部遷移が分かる形で開く。URL 未登録の施設ではボタンを表示しない。
- **AC-11**: 「この情報が古い場合は知らせる」から Google フォームへ**新しいタブ**で遷移できる。利用者を識別するパラメータをフォームへ渡さない。
- **AC-12**: 全詳細ページ下部に「今すぐ助けが必要な場合」共通セクションが固定表示され、通常の検索結果と区別されている。子ども向けの**相談窓口**（24時間こどもSOSダイヤル・チャイルドライン）を主に置き、いのちに関わる危険の**通報先**（110/119）は区別して併記する。電話番号はタップで発信できる。
- **AC-13**: 検索内容が URL に含まれず、検索履歴・アカウント・行動追跡・セッションリプレイのいずれも存在しない。
- **AC-14**: レスポンシブ対応。768px 未満は1カラム（絞り込みは折りたたみ）、**768px 以上**は結果画面で左に絞り込み・右に結果の2カラム。

## 6. 機能要件（サマリ）

FR は [`functional-design.md`](./functional-design.md) で詳細化する。ウィザード仕様（Q1〜Q3 の選択肢・分岐・自由記述必須）、結果の絞り込み・並び替え、詳細ページ項目、データの確認状況、報告導線、緊急セクションを含む。

## 7. 非機能要件

- **プライバシー・安全（最重要）**:
  - アカウント登録を求めない / 検索履歴を保存しない / 検索内容を URL に含めない / 広告・行動追跡を導入しない / セッションリプレイを使用しない。
  - 子どもや家族を自動判定しない。虐待・自傷・自殺などのリスクを AI で判定しない。
  - 緊急時の相談先は通常の検索結果と分けて案内する。
  - 本サービスは医療・法律・福祉の専門的判断や緊急機関の代替を目的としない。
- **アクセシビリティ**: WCAG 2.1 AA を目標。キーボード操作・スクリーンリーダー・色コントラスト・十分なタップ領域。
- **情報の信頼性・透明性**: 各情報に出典・最終確認日・確認状況を明示。不明な情報を推測で埋めず、`不明`/`未確認`/`要確認` として扱う。閲覧数・口コミ・人気度によるランキングはしない。
- **パフォーマンス**: モバイルファースト。静的生成中心で高速表示。詳細は [`architecture.md`](./architecture.md)。
- **多言語化**: MVP は日本語。将来の i18n を阻害しない設計。
- **アクセス解析**: 詳細ページ閲覧数と「公式サイトを見る」クリック数のみ。個人を特定しない。

## 8. 成功の定義（MVP）

- 横浜市内の不登校支援について、**30〜50件**の支援情報を、出典と確認日付きで掲載できている。
- 利用者が3問に答え、迷わず自分に合いそうな支援先を**2〜3件**見つけられる。
- サイトの規模拡大よりも、上記の「見つけられる」体験の質を優先する。

## 9. スコープ外（MVP では作らない）

- 施設情報を編集する管理画面 / サイト内の報告フォーム・管理機能（報告は Google フォームで代替）。
- バックエンド DB・ログイン・ユーザーアカウント。
- 不登校以外の領域（メンタルヘルス、ヤングケアラー、虐待・養育困難、生活困窮、ひとり親、発達・障害 等）— 将来拡張。
- ランキング・口コミ・レコメンド最適化。
