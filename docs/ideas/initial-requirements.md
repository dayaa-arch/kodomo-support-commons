## プロダクトの目的

横浜市にある子ども・家庭向けの支援情報を、探しやすく・比較しやすく・利用につながりやすい形で整理し、公共的なデジタル基盤として公開する OSS。MVP は「横浜市内の不登校支援」を対象とする。

## 対象利用者

- **主対象**: 子ども本人 / 保護者・家族 / 学校関係者
- **対象範囲**: 子どもに関わるすべての人
- **最初の利用場面**: 保護者が、自分の子どもの不登校について、学校以外に相談したいと思ったとき

## 現在の主な課題

- 「横浜市 不登校支援」等で検索しても、横浜市の分かりにくいポータルが中心に表示される
- 支援先ごとの違いや、問い合わせ前に確認できる公開情報が直感的に把握しづらい

## MVP で重視する改善方向

- UI を直感的にする
- 公開情報は、問い合わせをしなくても分かりやすく確認できるようにする

## 問い合わせ前に確認したい基本情報

対象地域 / 相談内容 / 費用 / 予約の要否 / 相談方法 / 匿名相談の可否 / 保護者だけでも相談可能か / 運営主体 / 受付時間

## 検索・絞り込み方法

質問に対してキーワードボタンで回答し、支援先候補を段階的に絞り込む。**MVP では質問は3問まで**（4問目は設けない。運営開始後に実利用データを見て拡張）。

### Q1. 誰のために探していますか（単一選択・分岐）

選択肢: 子ども本人 / 自分の子ども・家族 / 学校の児童・生徒 / 支援している子ども / その他

- 「その他」選択時のみ自由記述欄を表示し、**入力必須**。
- 設計意図: 利用者の立場に応じて、その後の質問内容と表示する支援情報を分岐させる。

### Q2. どんなことで困っていますか（単一選択・最も困っているものを1つ）

選択肢: 学校に行けない・行きづらい / 気分の落ち込み・不安 / 家庭や親子関係 / いじめ・友人関係 / 生活や経済面 / 子どもの世話や家族のケア / その他

- 「その他」選択時のみ自由記述欄を表示し、**入力必須**（未入力では次へ進めない）。
- 要件整理: 相談テーマを選び、その後の候補を大きく絞り込む。

### Q3. どの地域で探していますか（単一選択・横浜市18区）

鶴見区 / 神奈川区 / 西区 / 中区 / 南区 / 港南区 / 保土ケ谷区 / 旭区 / 磯子区 / 金沢区 / 港北区 / 緑区 / 青葉区 / 都筑区 / 戸塚区 / 栄区 / 泉区 / 瀬谷区

- 検索結果: 選択した区を優先表示し、通いやすい隣接区の支援先もあわせて表示する。
- 隣接区の表示方法: 各支援先カードに所在地の区名を分かりやすく表示し、選択区と隣接区を一目で区別できるようにする。
- 設計意図: 入力はシンプルに保ちつつ、利用可能な近隣の支援先を取りこぼさない。

## 検索結果画面

- 該当する支援先をカード形式の一覧で表示する。
- 初期表示件数は固定せず、合致件数を「検索結果 ○件」として明示する。
- 各カードの表示項目: 順位 / 施設名 / 運営主体 / 概要 / 区名 / 相談方法 / 費用 / 対象者・相談条件を示すタグ / 情報の確認状況 / 詳細ページへの導線。
- 「最も困っていること」を軸に表示。選択区の施設を優先しつつ隣接区も含める。
- 検索結果画面から条件を変更・再検索できる。
- **並び順**: 選択区の施設を優先 → 選択区内は回答条件との一致度が高い順 → 隣接区の施設はその後（同様に一致度順）。
- レイアウト: デスクトップは左に絞り込み条件・右に結果の2カラム。**モバイルファースト**で開発し、モバイルは1カラム縦並び、絞り込みは上部ボタン/ドロワーで開閉。
- ページネーション・追加読み込み・表示上限は、登録施設数と操作性を確認して決定する。

## 施設詳細ページ（モバイルファースト・縦方向に読みやすく配置）

表示項目:

- パンくずリスト
- 施設名
- 運営部署・運営主体
- 施設を表すイラストまたは画像
- 特徴ラベル（費用 / 保護者相談可 / 予約可 / 公式情報確認済み 等）
- 施設の概要説明
- 何を相談できるか
- 誰が利用できるか
- 利用までの流れ
- 相談方法
- 費用
- 利用条件
- 情報の出典
- 最終確認日
- 情報が古い場合の報告導線
- 緊急時の相談先

### 未確認・未掲載の項目の表示

該当項目を空欄にせず「公式サイトで確認してください」と表示し、「公式サイトを見る」導線とあわせて案内する。

### 公式サイトへの導線

- 「公式サイトを見る」ボタンを表示。押下で登録された公式サイトへ遷移。
- 公式サイト URL 未登録の施設ではボタンを表示しない。
- 遷移は**新しいタブ**で開き、外部サイトへの遷移であることが分かる表示とする。

### 情報が古い場合の報告方法

- 「この情報が古い場合は知らせる」ボタンから、運営者が用意する **Google フォーム**へ遷移。
- MVP ではサイト内に専用の報告フォームや管理機能を実装しない。

### 緊急時の相談先

- 全施設の詳細ページ下部に「今すぐ助けが必要な場合」共通セクションを固定表示。
- 緊急通報および公的な相談窓口への導線を掲載。施設ごとの情報と区別し、すぐ認識・利用できる表示とする。

## 情報の確認状況（信頼性表示）

- 運営者確認済み / 公式情報確認済み / 未確認 の3段階を表示する。
- 閲覧数・口コミ・人気度によるランキングは行わない。

## OSS における施設情報の登録・更新

- 施設情報の正本は GitHub リポジトリ内の YAML / JSON データファイル。
- 新規登録・修正は Pull Request で行う（外部コントリビューターも参加可）。
- 一般利用者からの修正依頼は Google フォームで受け付ける。
- 運営者または承認されたメンテナーによるレビューを公開前に**必須**とする。
- MVP では施設情報を編集する管理画面を実装しない。

## MVP のアクセス解析

- 施設詳細ページの閲覧数を計測する。
- 「公式サイトを見る」ボタンのクリック数を計測する。
- MVP では上記2項目のみを対象とする。

## MVP スコープの目安

- 対象: 横浜市内の不登校に関する支援資源。
- 初期目標: 30〜50件程度の支援情報を、出典と確認日付きで掲載。
- 規模拡大より、利用者が迷わず自分に合いそうな支援先を2〜3件見つけられることを重視。

## プライバシー・安全の原則

- アカウント登録を求めない / 検索履歴を保存しない / 検索内容を URL に含めない / 広告・行動追跡を導入しない / セッションリプレイを使用しない。
- 子どもや家族を自動判定しない。虐待・自傷・自殺などのリスクを AI で判定しない。
- 緊急時の相談先は通常の検索結果と分けて案内する。
- 本サービスは医療・法律・福祉の専門的判断や緊急機関の代替を目的としない。
